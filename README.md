# BIOKERA — открытие кабинетов

Адаптивный сайт партнёрского проекта: оборудование BIOKERA и MaxFit, три формата открытия, сопровождение, финансовый калькулятор и подготовка обращения.

Публикация: https://koraevgog-create.github.io/biokera-franch/

## Устройство

Статический сайт без сборки. Основные файлы: `index.html`, `design.css`, `enhancements.js`. В GitHub Pages используется ветка main, корневая папка.

- Адаптивная навигация, доступные состояния фокуса, FAQ.
- Калькулятор с ползунками и вводом точных значений, сценариями и проверкой вместимости.
- Кнопки форматов выбирают соответствующий вариант в форме.
- Форма готовит обращение: черновик в Telegram @RustUst, копирование и переход в MAX по ссылке из предоставленного QR. Отправку подтверждает сам посетитель в мессенджере. Сайт не хранит данные формы. По кнопке «Обсудить мой расчёт» в сообщение включаются параметры сценария.

## Изображения

BIOKERA и интерьеры — визуализации концепции из существующих материалов проекта. Изображение MaxFit Active Lux взято с сайта производителя: https://maxfit.su/assets/img/product-lux.jpg, источник указан в подвале. Назначение и итоговая комплектация согласуются по конкретной модели.

## Проверка перед рекламой

Уточнять актуальную комплектацию, договорную сторону BIOKERA, срок гарантии и условия доставки при подготовке предложения. Партнёрская цена кровати — 195 000 ₽ вместо 265 000 ₽; MaxFit — от 1 млн ₽ за аппарат. Сопровождение согласуется индивидуально, регулярных платежей нет. Калькулятор показывает сценарий; его результат не является обещанием дохода.


## Обновление продающей страницы

Первый экран с визуализацией кабинета, личным сопровождением Георгия Кораева и стартовыми ориентирами. Форматы вынесены перед оборудованием; подробности сметы доступны в раскрывающемся блоке. Добавлены изображения `salon-hero-v2.webp`, `launch-planning-v2.webp` и настоящий портрет из предоставленной MAX-визитки (показывается через CSS-кадрирование файла `georgiy-profile-source.jpg`). На телефонах доступна фиксированная кнопка связи, скрываемая на первом экране и в разделе контактов.

Форма подготавливает сообщение; посетитель самостоятельно отправляет его в Telegram или MAX. Подтверждения автоматической отправки нет. Логика и значения сценариев калькулятора сохранены.
