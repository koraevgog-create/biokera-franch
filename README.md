# BIOKERA — открытие кабинетов

Адаптивный сайт партнёрского проекта: оборудование BIOKERA и MaxFit, три формата открытия, сопровождение, финансовый калькулятор и подготовка обращения.

Публикация: https://koraevgog-create.github.io/biokera-franch/

## Устройство

Статический сайт без сборки. Основные файлы: `index.html`, `design.css`, `enhancements.js`. В GitHub Pages используется ветка main, корневая папка.

- Адаптивная навигация, доступные состояния фокуса, FAQ.
- Калькулятор с ползунками и вводом точных значений, сценариями и проверкой вместимости.
- Кнопки форматов выбирают соответствующий вариант в форме.
- Форма готовит текст обращения для копирования или скачивания; автоматическая отправка не подключена.

## Изображения

BIOKERA и интерьеры — визуализации концепции из существующих материалов проекта. Изображение MaxFit Active Lux взято с сайта производителя: https://maxfit.su/assets/img/product-lux.jpg, источник указан в подвале. Назначение и итоговая комплектация согласуются по конкретной модели.

## Проверка перед рекламой

Указать контакт для прямой отправки обращений и подтвердить актуальную смету, коммерческие условия и комплект документов. Калькулятор показывает сценарий; его результат не является обещанием дохода.
