# Biokera — сайт открытия кабинетов

Продающий одностраничник о самостоятельной бизнес-модели кабинета аппаратного массажа Biokera и продажах оборудования.

## Запуск GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Branch: **main**, Folder: **/(root)**, затем **Save**.
4. Сайт: https://koraevgog-create.github.io/biokera-franch/

## Что уже работает

- Адаптивный дизайн, навигация, FAQ
- Интерактивный калькулятор, без серверных запросов
- SEO: title, description, canonical, OpenGraph, JSON-LD, robots.txt и sitemap.xml
- Форма собирает текст заявки, но **не отправляет и не сохраняет данные**

## Что важно подключить перед рекламой

- Реальные фотографии Biokera PRO N7, ремня и оборудования для ног с правами на использование
- Контакт для заявок (Телеграм, телефон или CRM)
- Политику обработки персональных данных и фактический статус лица, оказывающего услуги
- Проверенные условия поставки, коммерческого использования устройств и прав на фирменные обозначения

Сайт не заявляет официального статуса франшизы Biokera. Финансовый калькулятор демонстрационный.
